iQizo - Account & Data Deletion

iQizo allows users to permanently delete their gameplay profile and all associated data directly from inside the app.

How To Delete Your Profile

  1. Open the iQizo app
  2. Click the Switch Profile icon at the top-right corner next to the theme switch
  3. On the Profile screen, click the red Delete icon next to the profile you want to remove
  4. A confirmation popup will appear asking if you are sure you want to delete the selected profile
  5. The popup will clearly mention that all IQ Coins, progress, achievements, and global ranking data will be permanently lost
  6. Type the profile name exactly as shown to confirm deletion
  7. Click Proceed to permanently delete the profile and associated data
Important:
Profile deletion is permanent and cannot be undone.

Data Deleted

When a profile is deleted, the following data is permanently removed:

  • Profile information
  • Selected avatar
  • Optional bio
  • Quiz progress
  • Achievements
  • IQ Coins
  • Leaderboard and ranking data
  • Gameplay statistics
  • Associated local device data

Data Retention

Once deletion is completed:

  • No backup of the deleted profile is retained
  • No gameplay progress or statistics are stored after deletion
  • Deleted data cannot be restored
